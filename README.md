# Apollo Remote
Apollo Remote Control that works with Apple OEM Volume Keys with a cutomizable Mute Key to Activate Mono or DIM Switch,Sample Rate Selection. Clean Swift UI with slider options, Live Menu Bar Meters,and features that actually matter when you’re working with high output studio monitors. Protective Volume Lock + Live Status Menu bar, Multiple HUD Displays,to choose from
