# Apollo Remote
Apollo Remote Control that works with Apple OEM Volume Keys with a cutomizable Mute Key to Activate Mono or DIM Switch,Sample Rate Selection. Clean Swift UI with slider options, Live Menu Bar Meters,and features that actually matter when you’re working with high output studio monitors. Protective Volume Lock + Live Status Menu bar, Multiple HUD Displays,to choose from. First time ever coding like that but it was made with love i can assure you. New to Github and want to credit all of the features ive gathered from everybody here to make the ultimate APP! People are charging for this... All credit to OG Sources where its do.
